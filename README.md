# Le Coup de Foudre Paris

The first pass of the site contains one responsive home route in the Next.js App Router.

## Run locally

```bash
npm install
npm run dev
```

The concierge form opens a prefilled email to `contact@lecoupdefoudre-paris.com`; replace that address if the official enquiry address differs. The `1,500+` experience count is from the supplied Beta mockup and should be confirmed before publication.
